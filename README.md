# 记账 · 2026 年 11 月

个人支出账本，纯静态单文件网页，不需要后端或数据库。

在线查看：<https://532313.github.io/jizhang-2026/>

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 生成的账本网页（GitHub Pages 首页） |
| `2026年11月账单.html` | 同一份页面，本地双击用 |
| `ledger_data.py` | 所有账目，唯一数据源 |
| `make_ledger_html.py` | 把数据渲染成网页 |

## 更新

```bash
python3 -B make_ledger_html.py
```

改完 `ledger_data.py` 后跑一次，两个 HTML 会一起重新生成。

## 分类

| 类型 | 含义 | 例子 |
|---|---|---|
| 日常 | 当天或几天内就消耗掉 | 外卖、交通、买菜 |
| 固定 | 按月必交、金额稳定 | 房租、水电、话费 |
| 预付 / 专项 | 钱已付、以后才用 | 充值、机票、大件耐用品 |
